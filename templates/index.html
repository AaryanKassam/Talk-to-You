Type like you.

Add up to five chat exports. TTYS reads your own messages out of them, builds an n-gram model of how you write, and predicts your next words while you type.

Drop your chat exports here

WhatsApp .txt, or .html from iMessage, Telegram Desktop, Instagram, Facebook Messenger or Discord.

Getting the file out of WhatsApp

  1. Open the chat you want to use.
  2. Tap the chat name at the top, then Export Chat.
  3. Choose Without Media.
  4. Save the .txt file, then add it here.

Other apps

  1. iMessage: export the conversation with imessage-exporter as HTML, then add the .html file for that chat.
  2. Telegram Desktop: chat menu, Export chat history, format HTML.
  3. Instagram or Facebook: Accounts Centre, Download your information, format HTML, then use the message_1.html files.
  4. Discord: export the channel with DiscordChatExporter as HTML.

Everything runs on this machine. Files are parsed in memory, never written to disk, and never sent to any external service. There is no API key and no account. Read the details.
