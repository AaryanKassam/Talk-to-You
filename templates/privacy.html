Privacy

Short version: your messages never leave this machine.

Where your file goes

The export you upload is sent to a Flask server running on 127.0.0.1, which is this computer and nothing else. The file is read into memory, parsed, and discarded. It is never written to disk, never copied into a database, and never included in a log line.

What is kept, and for how long

While the server is running it holds the parsed messages and the word counts of the identity you selected, in memory only. Pressing Start over clears them. Stopping the server clears them. There is no cache and no session file to clean up afterwards.

Network calls

This app makes no requests that leave your machine. There is no API key, no account, no analytics, and no font or script loaded from a CDN. The prediction model is an n-gram table built here in a fraction of a second, and the chat replies are retrieved from your own message history, so there is nothing to send anywhere.

Chat mode and the local model

Chat mode works with nothing installed: it finds the closest thing anyone ever said to you and returns the reply you actually gave. If you install Ollama, TTYS will additionally call it at 127.0.0.1:11434 to adapt those replies to new questions. That is a local process on this machine, not a hosted service, and the request never touches the network. Your messages are in that prompt, so they reach the local model, and no further.

Nothing is ever sent to a hosted model. There is no cloud fallback in this build, deliberately, so there is no setting you can leave switched on by mistake.

Other people in the chat

A group export contains other people's messages too. TTYS lists every sender so you can pick yourself, and after that it uses only the messages belonging to the identity you chose. The rest are held in memory for the life of the process and then dropped. Since the export is not yours alone, treat it with the care you would want the other people in that chat to use.
